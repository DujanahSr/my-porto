# Abu Dujanah Siregar – Portfolio

A modern, high-performance portfolio website built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. Designed with a sophisticated "Deep Ocean Editorial" theme to showcase projects, skills, and certifications elegantly.

## Features

- **Bilingual Support (i18n):** Seamlessly toggle between English (EN) and Indonesian (ID) using a custom React Context.
- **Fluid Responsive Design:** Carefully crafted layouts that look impeccable on all devices, down to 320px ultra-small screens.
- **Premium Aesthetics:** Dark mode aesthetic with custom typography (`Cormorant Garamond`, `DM Sans`, and `Space Mono`), glassmorphism effects, and smooth animations.
- **Custom Cursor:** Includes a magnetic, interactive custom cursor to enhance user experience.
- **Optimized Performance:** Fully SSR/SSG capable Next.js architecture with optimized images and fonts.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is fully optimized and ready to be deployed on **Vercel**. 
Simply connect your GitHub repository to Vercel and it will automatically build and deploy.

```bash
npm run build
```
